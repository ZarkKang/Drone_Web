# 无人机智能仓储一体化平台 (Drone_Web)

本系统是一款专为无人机仓储盘点与物流视觉存证设计的智能一体化控制台。系统采用 **Node.js (Express) + MongoDB** 作为核心后端架构，前端采用独创的单页持久化扫描（SPA）机制，配合底层的自适应图像处理算法，解决了无人机在高速移动、光照不均、多物理摄像头冲突环境下的二维码高效抓拍与数据留存难题。

---

## 核心技术亮点

### 1. 单页持久化扫描（SPA）不间断引擎

* **痛点解决**：传统网页多页面跳转时会彻底终止摄像头流，导致无人机盘点中断或重新初始化延迟。
* **架构设计**：采用全异步视图洗牌机。将摄像头 `<video>` 作为全局实体常驻于静默后台。
* **可视化流分发**：
* **主页（仪表盘）**：自动将全局视频帧以 **60帧/秒** 渲染至可视化 `Canvas` 中，并叠加动态红外/激光扫描线波纹特效与翠绿色物理边界追踪框。
* **切换页面（如数据库/设置）**：系统自动切换为内存**离屏盲扫模式**。视频流不断、扫描不终止，用户占用界面被释放，确保数据存证无漏报。



### 2. 物理存证镜头锁定与设备热重载

* **多设备支持**：系统能够自动枚举无人机机载有线/无线摄像头、USB 采集卡及前后置镜头。
* **硬件凭证锁定**：通过浏览器 `LocalStorage` 强行锁定指定相机的底层 UUID 凭证。防止在多设备环境下因系统重启造成的输入源无序漂移。
* **实时热重载**：在“相机设置”修改后，后台扫描引擎无缝重定向，无需刷新整页。

### 3. 高速环境 QR 识别优化器 (`qr-recognition-optimizer.js`)

* 针对无人机运动模糊（Motion Blur）和仓库暗光环境，内置自适应算法：
* **预处理与自适应增强**：自动优化动态对比度与锐度（Sharpness）。
* **精准裁剪取证**：识别成功后，自动根据物理坐标提取二维码局部的微秒级裁剪切片（QR Slice），并与当前全景现场图（Env Image）一同打包上传。
* **时间窗口防震荡锁**：后端对同一货物 ID 开启 5 秒时间窗口拦截，防止因高帧率重复识别造成数据库冗余。

## 🚀 快速开始（Docker 容器化部署）

系统已完成全套生产环境容器化封装，无需在本地配置 Node.js 和 MongoDB，只需一行命令即可全栈拉起。

### 前提条件

* 已安装 [Docker](https://www.docker.com/) 和 [Docker Compose](https://docs.docker.com/compose/)。
* 浏览器访问时需使用 `localhost` 或启用 `HTTPS` 协议，否则浏览器出于安全策略将拒绝开放摄像头底层权限。

### 一键运行

在项目根目录下执行以下命令：

```bash
docker-compose up --build

```

系统启动后，各模块映射如下：

* **前端控制台 / API 服务**：`http://localhost:3000`
* **MongoDB 数据库服务**：`http://localhost:27017`（数据已持久化至本地 `mongo-data` 卷中）

## 🛠️ 后端基础 API 导向

平台提供了轻量高效的异步通信总线：

* `POST /api/save-record`：上传捕获到的存证记录。请求体大小上限已放宽至 **50MB**（确保 Base64 双高清晰度大图安全传输）。
* `GET /api/records`：供存储中心无刷新异步轮询使用的最新存证流水接口。
* `DELETE /api/delete-record/:id`：单条存证记录的安全物理擦除。
